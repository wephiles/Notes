# 制表符

为了方便以后使用，这里是一整套常用的制表符，直接复制即可：

- **四个角：** `┌` `┐` `└` `┘`
  
- **十字交叉：** `├` `┤` `┬` `┴` `┼`
  
- **直线：** `─` `│`
  
- **双线版：** `╔` `╗` `╚` `╝` `╠` `╣` `╦` `╩` `╬` `═` `║`
  

```plaintext
 #  ┌ ┐ └ ┘  
 # ├ ┤ ┬ ┴ ┼  
 # ─ │
 
 # ╔ ╗ ╚ ╝ ╠ ╣ ╦ ╩ ╬ ═ ║
```
