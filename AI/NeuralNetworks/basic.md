# 0. 学习路径

从 Python 开发转 AI，你的起点其实比大多数人都要好——**代码能力、工程思维和调试直觉都能直接复用，真正要补的只有三块：数学直觉、神经网络原理、以及一两个实战项目经验**。推荐的主线路径是：Python 科学计算栈 → 按需补数学 → 传统机器学习入门 → 神经网络核心（吴恩达 + 动手学深度学习）→ 选定方向做项目，全程大概 4~6 个月可以完成从零到能做项目的跨越。
## 0.1 为什么你转型比零基础的人快
程序员转 AI 的核心优势在于**工程化能力是当前 AI 落地最稀缺的一环**：数据清洗、管道搭建、缓存设计、异常处理、系统架构——这些恰恰是算法研究员的短板，而你已经具备。AI 岗位大致分几类：算法工程师（偏数学和模型）、机器学习工程师（偏工程落地）、NLP/CV 工程师（偏领域任务）、MLOps 工程师（偏部署运维）。对有 Python 工程背景的你来说，**机器学习工程师和 MLOps 方向的性价比最高**，因为它对数学要求相对适中，而对工程能力要求极高——这正是你的主场。

| 阶段                    | 核心内容                                                     | 推荐资源                                                     | 时间参考                       |
| ----------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ | ------------------------------ |

这套路径的关键逻辑是：**先用传统机器学习建立“模型、损失、优化”的范式认知，再学神经网络就能无缝衔接，最后用 PyTorch 把理论落地成代码**。

## 0.3 各阶段要点详解

### 0.3.1 阶段①：Python 科学计算栈——别小看这一步

很多开发者觉得“我都会 Python 了还学什么”，但 AI 需要的是**数据科学风格的 Python**：列表推导式、生成器、装饰器、类型提示这些是基本功，更重要的是三大件——NumPy 的广播机制和矩阵运算（神经网络底层全是矩阵乘法）、Pandas 的数据增删改查与聚合（数据预处理的日常）、Matplotlib/Seaborn 画图（不是为了好看，是为了看懂数据分布和损失曲线）。避坑指南：**不用去学 Django/Flask，这时候完全用不上**。
验收标准：能独立用 Pandas 读取 CSV、完成清洗和缺失值填充，用 NumPy 做数值计算，用 Seaborn 画出特征相关性热图。
### 0.3.2阶段②：数学补课——最小必要知识集
这是大多数人最容易陷入的两个误区之一：要么死磕半年数学一行代码不写，要么完全跳过数学导致后面看不懂反向传播。**正确策略是“碎片化补充”**：学到梯度下降时补微积分的偏导和链式法则，学到矩阵运算时补线性代数的乘法和转置，学到 Softmax 时补概率论的最大似然估计。
具体需要掌握的最小集：
- **线性代数**：向量、矩阵乘法、转置、逆矩阵、点积（神经网络本质是矩阵相乘）
- **微积分**：导数、偏导数、链式法则（反向传播的核心就是链式求导）
- **概率统计**：概率分布（高斯、伯努利）、期望、方差、条件概率、最大似然估计、交叉熵
推荐资源：3Blue1Brown 的《线性代数的本质》系列视频（建立几何直觉）+ Khan Academy 微积分课程（补导数和链式法则）。**目标不是会推导复杂公式，而是看到公式能理解它在干什么**。
### 0.3.3 阶段③：传统机器学习——理解“模型训练”的范式
为什么不直接学神经网络？因为传统机器学习的概念体系（训练集/测试集、损失函数、过拟合/欠拟合、正则化、评估指标）是神经网络的地基，先在简单模型上把这些概念吃透，后面学深度学习会轻松得多。
吴恩达的《Machine Learning Specialization》是公认的最佳入门课——它不需要深厚的数学背景，每个概念都有直观的可视化解释，而且 2022 年新版已经全面改用 Python。配合 scikit-learn 实战几个经典项目：鸢尾花分类、房价预测、泰坦尼克号生存预测——这些都是数据集好找、代码简单的入门项目。
验收标准：能独立完成“获取数据 → 清洗预处理 → 划分数据集 → 调用 Sklearn 搭建模型 → 训练 → 评估 → 调参优化”的完整流程。

### 0.3.4 阶段④：神经网络核心——必须啃下来的硬骨头
这是转型的分水岭，也是第二个大坑的高发区（很多人在这里只看视频不动手，最后什么都没学会）。**核心知识点清单**：
- **感知机与多层感知机（MLP）**：神经元模型、权重与偏置、前向传播
- **激活函数**：Sigmoid、Tanh、ReLU 及各自的问题（梯度消失、死亡 ReLU）
- **损失函数**：MSE（回归）、交叉熵（分类）
- **反向传播算法**：链式法则的具体应用，梯度如何从输出层反向传到输入层
- **梯度下降及其变体**：批量梯度下降、小批量梯度下降、学习率的作用
- **优化器**：SGD、Momentum、AdaGrad、RMSProp、Adam
- **正则化技巧**：Dropout、BatchNorm、权重衰减
**强烈建议在这个阶段用纯 NumPy 手写一个两层的全连接网络，跑 MNIST 手写数字识别**——不求效果多好，但求把前向传播、损失计算、反向传播、参数更新的每一步都亲手实现一遍。这一步做完，你对神经网络的理解会脱胎换骨。
配套资源首选：吴恩达《Deep Learning Specialization》前两门课（神经网络基础 + 改善深层神经网络）+ 斋藤康毅的《深度学习入门：基于 Python 的理论与实现》（俗称“鱼书”，图解友好，专门讲原理推导）。
### 0.3.5 阶段⑤：框架与进阶架构——从原理到工程
框架选择上，**直接学 PyTorch**，不用纠结。它是学术界和工业界的事实标准，动态计算图对调试友好，社区资料最丰富。PyTorch 要掌握的核心是：张量操作、自动求导机制、Dataset/DataLoader 数据加载、继承 `nn.Module` 搭建网络、训练循环的完整流程。
主流网络架构按顺序学：
- **CNN（卷积神经网络）**：卷积层、池化层、Padding、Stride，经典模型 LeNet → AlexNet → VGG → ResNet 的演进逻辑（重点理解残差连接为什么能让网络加深）
- **RNN/LSTM/GRU**：处理序列数据，理解 RNN 的长期依赖缺陷和 LSTM 门控机制如何解决它
- **Transformer 与注意力机制**：现代大模型的基石，必须吃透 Self-Attention 的原理、多头注意力、Encoder-Decoder 结构
这一阶段的首选教材是**李沐的《动手学深度学习》（D2L）**，理由有三：一是每个概念都配可运行的 Jupyter Notebook 代码，公式与实现一一对应；二是中文原生，被全球 70 多个国家 500 多所大学用作教材；三是作者在 B 站有配套视频课程，可以对照学习。书中每节的结构都是“文字讲解 + 数学推导 + 代码实现 + 结果可视化”，读完一节就动手跑一节，改改超参数看输出变化——这种学习方式能把理论和实战能力同步提上来。
如果想深入理解底层原理，**Andrej Karpathy 的《Neural Networks: Zero to Hero》系列视频是绝佳补充**——它从零开始手写反向传播，一路实现到 GPT 级别的语言模型，前提是你要有扎实的 Python 基础和基本微积分知识，这正好匹配你的背景。
### 0.3.6 阶段⑥：项目实战——循序渐进的清单
理论学完后必须靠项目落地，推荐按难度递进：
**入门级**（验证框架掌握）：
- PyTorch 搭建 CNN 做 CIFAR-10 图像分类
- LSTM 做时间序列预测（气温/股价）
**进阶级**（领域深化）：
- CV 方向：复现 ResNet 做猫狗分类器，或用 YOLO 做目标检测
- NLP 方向：用 Transformer 做文本分类、情感分析，或实现简单文本生成
- 参加一场 Kaggle 入门竞赛（如 House Prices、Digit Recognizer）
**高阶级**（对接当前热点）：
- 用 Hugging Face Transformers 微调一个预训练模型（BERT 做文本分类，或 Llama/Qwen 做特定任务）
- 搭建一个基于 RAG 的“个人知识库问答助手”：上传 PDF，让大模型基于文档内容回答问题——这个项目会逼你学会 Embedding、向量数据库（Chroma/Milvus）、LangChain 等一整套当前最热门的技术栈

## 0.4 高效学习方法与避坑指南
**最核心的原则：以代码驱动学习，理论够用就好。** 具体做法是“学一个概念 → 立即用代码实现 → 修改参数观察输出变化 → 再回头看公式加深理解”。你的 Python 背景在这里是巨大优势——别人还在纠结语法时，你已经可以直接改模型代码了。
**要避开的三个典型坑：**
1. **数学完美主义**：先花半年啃完《统计学习方法》的所有公式推导，一行代码不写，最后枯燥到放弃。正确做法是碎片化补充，学到哪补到哪。
2. **理论实践脱节**：只看视频和书，不动手敲代码。神经网络必须亲手复现才能真懂——看十遍反向传播的推导，不如自己用 NumPy 写一遍。
3. **好高骛远**：一上来就想学 GPT、Stable Diffusion、大模型微调，底层原理完全不懂，遇到报错就束手无策。正确顺序是 Python → 机器学习基础 → 手写简易神经网络 → PyTorch → CNN/RNN/Transformer → 大模型应用。
**时间投入参考**：如果每天能保证 2~3 小时，按上面的路线走完阶段①~⑤大约需要 4~6 个月；如果全职学习可以压缩到 2~3 个月。关键是保持节奏，不要前松后紧。

## 0.5 长期方向选择
学完基础后，建议根据兴趣和市场需求选一个方向深耕，不同方向对应不同的岗位和技能重点：
- **计算机视觉（CV）**：图像分类、目标检测、图像分割、多模态。岗位集中在安防、自动驾驶、医疗影像、工业质检。
- **自然语言处理（NLP）**：文本分类、情感分析、机器翻译、对话系统。当前与 LLM 高度融合，是就业面最广的方向之一。
- **大模型应用工程（LLM Engineer）**：Prompt 工程、RAG、Agent、模型微调与部署。这是 2024 年以来增长最快的岗位方向，企业需求量极大，而且**最看重工程能力而非算法研究能力——对你这样的转型者最友好**。
- **MLOps / 机器学习工程**：模型部署、监控、流水线自动化、性能优化。本质是“懂机器学习的运维/后端工程师”，你的工程背景在这里价值最大。
**转型不是从零开始，而是工程能力的升维。** 保持“螺旋上升”的节奏——边学理论边做项目，遇到瓶颈再回头补原理，你会发现从 Python 开发到 AI 工程师的距离，远比想象中近。

# 1. Python 科学计算栈

## 1.1 `Numpy`

### 1.1.0 详细教程

> 请参考 [`./Numpy.md`](Numpy.md)

### 1.1.1 必须精通

标准是：**不假思索就能用，不用查文档**。

| 知识点               | 具体内容                                                     | 为什么重要                                                   |
| -------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| **ndarray 核心属性** | `shape`、`dtype`、`ndim`、`size`                             | 看懂任何数组的第一反应就是先看 shape，调试 90% 的报错都从 shape 入手 |
| **数组创建**         | `np.array`、`zeros`、`ones`、`full`、`arange`、`linspace`、`random.randn/randint/rand` | 初始化权重、构造测试数据、生成模拟输入的基础操作             |
| **索引与切片**       | 基本切片 `a[1:3]`、花式索引 `a[[0,2,5]]`、布尔掩码 `a[a>0]`  | 布尔掩码是数据筛选的日常（见演示 4），深度学习里 label 筛选、样本过滤全靠它 |
| **广播机制** ⭐       | `(4,3)` 与 `(3,)` 运算自动对齐的规则                         | **全 NumPy 最重要也最容易出错的机制**（见演示 2）。标准化 `(X-mean)/std` 就是广播；反向传播里梯度对齐也是广播。规则：从右往左逐维比较，维度相等或其中一方为 1 才能广播 |
| **axis 参数** ⭐      | `sum/mean/max/argmax(axis=?)`                                | 理解“axis 就是沿该方向压扁”（见演示 3）。`X.mean(axis=0)` 对每个特征求均值，这是数据预处理天天用的操作 |
| **形状操作**         | `reshape`、`transpose`、`squeeze`、`expand_dims`、`flatten`/`ravel` | 神经网络里数据形状变换极频繁：`(batch, H, W, C)` 转 `(batch, C, H, W)` 就靠 `transpose(0,3,1,2)` |
| **向量化运算** ⭐     | 元素级加减乘除、`np.exp/log/sqrt/abs`、比较运算返回布尔数组  | 如演示 1 所示快 91 倍。**核心思维转变：写 NumPy 时忘掉 for 循环** |
| **矩阵运算**         | `@` 运算符、`np.dot`、`np.matmul`                            | 神经网络前向传播本质就是 `output = X @ W + b`                |
| **基础 dtype**       | `float32` vs `float64`、`astype` 转换                        | 深度学习默认用 `float32`（省一半显存），类型不匹配是常见报错来源 |

**这层的检验标准**：看到 `operands could not be broadcast together` 报错能立刻知道是 shape 不兼容、并知道怎么修。

### 1.1.2 需要知道

标准是：用到时能想起来

| 知识点                     | 具体内容                                                     | 使用场景                                                     |
| -------------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| **视图 vs 拷贝** ⚠️         | 切片返回视图（改一个影响另一个），花式索引/布尔索引返回拷贝；`copy()` 显式拷贝 | **这是一个大坑**：`b = a[:100]` 后改 `b` 会悄悄改掉 `a`，数据预理时容易出灵异 bug，值得专门花 20 分钟搞懂 |
| **拼接与堆叠**             | `concatenate`、`vstack`、`hstack`、`stack`（注意 `stack` 会新增维度） | 合并数据集、拼接特征                                         |
| **条件与裁剪**             | `np.where`（三元表达的向量化版）、`np.clip`                  | ReLU 就是 `np.maximum(x, 0)`，梯度裁剪用 `clip`              |
| **随机模块**               | `np.random.seed`（可复现性）、`shuffle`、`permutation`、`choice` | 打乱数据集、划分训练/测试集是每个项目的第一步                |
| **排序**                   | `np.sort`、`np.argsort`（返回排序后索引）                    | `argsort` 常用于“取 top-k”操作                               |
| **NaN 处理**               | `np.isnan`、`nanmean`、`nan_to_num`                          | 真实数据总有缺失值，但注意 `x[x!=x]` 这种技巧不如 `isnan` 直白 |
| **元素类型转换与运算规则** | 整数溢出行为、`float32` 与 `float64` 混算自动提升            | 避免精度陷阱                                                 |
| **基础线性代数**           | `norm`、`inv`、`solve`                                       | 学数学部分时会用到，深度学习直接用得不多                     |

### 1.1.3 了解即可

标准：知道存在，用的时候查文档。

- **`np.einsum`**：爱因斯坦求和约定，功能强大但学习曲线陡。等你在 PyTorch 里见到别人用它实现注意力机制时再回头学
- **`np.save/np.load`（.npy/.npz 格式）**：知道能存数组就行，AI 里更常用 Parquet/HDF5
- **结构化数组**：类似数据库表的数组，知道存在即可——实际数据处理会用 Pandas
- **内存布局**：`ascontiguousarray`、C 序 vs F 序、`strides`。PyTorch 的 `tensor.contiguous()` 报错时会用到，遇到再查
- **`np.vectorize`**：把任意 Python 函数“伪装”成向量化（其实并不加速），知道别误以为它性能好即可
- **`np.fft` 傅里叶变换**：信号处理方向才深入
- **`np.memmap` 内存映射**：处理超大文件时才有用

### 1.1.4 可跳过

对 AI 学习几乎无用

- **`np.matrix`**：已被官方弃用，全部用 `ndarray` + `@` 代替
- **`np.char` 字符串操作**：文本处理请直接用 Python 字符串或 Pandas
- **`np.datetime64` 深入用法**：时间序列处理用 Pandas 的更顺手
- **金融函数**（`fv`、`pv` 等）、**掩码数组**（`np.ma`）深入用法、**`np.polynomial`**
- **编写 C 扩展、ufunc 底层实现**：这是 NumPy 库开发者的事
- **`np.linalg` 的深水区**（SVD、QR 分解、特征分解）：学传统机器学习 PCA 时再回来补

### 1.1.5 `Numpy` 必须精通知识点

1. **向量化（快 91 倍）**——以后写 NumPy 代码时，看到自己写了 for 循环遍历数组，就要警惕
2. **广播**——`(4,3) - (3,)` 得到 `(4,3)`，`(3,)` 被自动“复制”了 4 份。试着故意写 `(4,3) - (4,)` 看看报错，加深理解
3. **axis**——`axis=0` 沿列压扁得每列的和，`axis=1` 沿行压扁得每行的和。**判断技巧：结果里丢掉了哪个维度**
4. **布尔掩码**——`scores[np.abs(scores) > 2.0]` 一行完成筛选，`mask.sum()` 直接数个数

### 1.1.6 学习方法与自检清单

**推荐节奏**（有 Python 基础，每天 1~2 小时）：

- **第 1~3 天**：过一遍 NumPy 官方 Quickstart（numpy.org 的 quickstart.html），只看第一层内容，每个 API 在 Jupyter 里亲手敲一遍
- **第 4~7 天**：去 GitHub 做 **`rougier/numpy-100`**（100 NumPy 练习题）的前 40 题，做不动就看答案、看懂再默写一遍
- **第 8~10 天**：不看任何资料，纯手写一个小项目：生成 1000 个样本的模拟数据 → 布尔掩码清洗 → 标准化（用广播）→ `@` 实现线性回归 → `axis` 求各特征统计量

**自检清单**（全部打勾才算过关）：

- [ ] `(3, 4)` 的数组和` (4,)` 的数组相加，能脱口而出结果 shape 是 `(3, 4)`
- [ ]  `X.sum(axis=0)` 为什么得到每列的和，能给别人讲明白
- [ ] 一行代码筛选出数组中所有大于均值且为偶数的元素
- [ ] 能解释为什么 `b = a[:100]; b[0] = 999` 会改变 `a`（视图）

- [ ] 能把 `(32, 28, 28, 3)` 的图片批量数据转成 `(32, 3, 28, 28)`（`transpose(0, 3, 1, 2)`）
- [ ] 知道 `float32` 和 `float64` 在深度学习中的取舍
- [ ] 写完一段代码扫一眼，能立刻发现哪里“该向量化却写了循环”

达到这个状态，NumPy 就可以“毕业”了，不必追求掌握 100% 的 API——**剩下的一律用时查文档**，这才是工程师使用工具库的正确姿势。之后进入 Pandas 学习时你会发现，很多操作（布尔掩码、axis、广播）在 Pandas 里是同一个思想，学习成本会大幅下降。
